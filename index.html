Head of Section Data Analyst

PT Karyainvestama Mining

Mengelola dan mengintegrasikan data lintas departemen (HRGA, Logistik, Plant, Engineering, HSE) untuk mendukung pengambilan keputusan berbasis data di lingkungan operasional pertambangan.

  • Mengembangkan sistem informasi internal berbasis web dan mobile (APK) untuk meningkatkan efisiensi administrasi perusahaan.
  • Mengelola database operasional lintas departemen — data karyawan, payroll, aset perusahaan, hingga logistik bahan bakar — secara terpusat.
  • Menyusun laporan rekapitulasi produksi harian hingga tahunan secara real-time, termasuk pemantauan biaya bulanan proyek.
  • Merancang dan mengelola infrastruktur jaringan internet (Wi-Fi) serta sistem pengawasan CCTV untuk kelancaran operasional area site.
  • Mengelola basis data izin tambang (mine permit) dan distribusi APD, serta menganalisis efisiensi performa unit melalui pemantauan idle time.
